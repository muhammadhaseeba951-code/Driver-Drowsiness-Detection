# Driver Drowsiness Detection using CNN (AlexNet)

## Project Overview

This project is a deep learning-based Driver Drowsiness Detection system developed using Convolutional Neural Networks (CNN). The objective of the project is to classify whether a driver is **drowsy** or **alert** using facial image data. This system can help reduce road accidents by detecting signs of fatigue and lack of attention.

The project was developed as part of a Data Science / Deep Learning assignment focused on image classification and real-world AI applications.

---

## Objectives

* Perform binary image classification
* Understand CNN-based image processing
* Apply AlexNet architecture for classification
* Train and evaluate a deep learning model
* Understand the concept of real-time driver monitoring systems
